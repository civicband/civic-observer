# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a System / Light / Dark theme to every user-facing CivicObserver page, with a navbar control, no flash on load, and no database changes.

**Architecture:** Enable Tailwind v4 class-based dark mode from a tracked source file, apply the theme from a tiny inline head script before paint, expose a three-state `window.civicTheme` controller, and add explicit `dark:` variants to every user-facing template. A template-scanning test enforces coverage of neutral surfaces, text, and borders.

**Tech Stack:** Django, Tailwind CSS v4 via `django-tailwind-cli`, HTMX, Alpine.js, localStorage, `prefers-color-scheme`.

**Spec:** `docs/superpowers/specs/2026-11-12-dark-mode-design.md`

> **Post-implementation note:** The ongoing theme controller moved from the inline head script to `frontend/js/theme.js` as an Alpine store during review. The inline script now only applies the no-flash boot state. The spec remains the authority; the Task 1 snippets below are historical.

## Global Constraints

- Theme storage key is `civic-theme`; values are `light` and `dark`; absent means `system`.
- Mode cycle is `system` → `light` → `dark` → `system`.
- Page background is `dark:bg-gray-950`; card/nav surfaces are `dark:bg-gray-900`; borders are `dark:border-gray-800` (subtle) or `dark:border-gray-700` (stronger).
- Primary text is `dark:text-gray-100`; secondary is `dark:text-gray-300`; muted is `dark:text-gray-400`.
- Never invert page images, user content, or code color swatches.
- Exclude `templates/email/`, `templates/admin/`, Django admin, and third-party dashboards.
- No database migration and no per-user preference.
- The theme bootstrap must run inline in `<head>` before the stylesheet to avoid a flash.

## Review Focus

- Stored dark theme with blocked localStorage must fall back to system without a JavaScript error or light flash.
- Invalid stored value must resolve to system mode.
- A theme change in another tab must update the current tab.
- The dark footer, page images, and user-selected color swatches must remain legible and must not be inverted.
- The mobile theme control must be reachable, labeled, and visible in both themes.

## Class Transformation Rules

Apply these mappings to every user-facing template. A single class attribute may need several additions.

| Light token | Required dark token family |
|---|---|
| `bg-white` | `dark:bg-gray-900` or `dark:bg-gray-950` |
| `bg-gray-50` | `dark:bg-gray-900` or `dark:bg-gray-800` |
| `bg-gray-100` | `dark:bg-gray-800` |
| `text-gray-900` | `dark:text-gray-100` or `dark:text-white` |
| `text-gray-800` | `dark:text-gray-200` or `dark:text-gray-100` |
| `text-gray-700` | `dark:text-gray-300` or `dark:text-gray-200` |
| `text-gray-600` | `dark:text-gray-300` |
| `text-gray-500` | `dark:text-gray-400` |
| `border-gray-200` | `dark:border-gray-800` |
| `border-gray-300` | `dark:border-gray-700` |
| `divide-gray-200` | `dark:divide-gray-800` |
| `divide-gray-300` | `dark:divide-gray-700` |
| `hover:bg-gray-50` | `dark:hover:bg-gray-800` or `dark:hover:bg-gray-900` |
| `hover:bg-gray-100` | `dark:hover:bg-gray-800` |
| `hover:text-gray-900` | `dark:hover:text-white` or `dark:hover:text-gray-100` |
| `hover:text-gray-700` | `dark:hover:text-gray-300` or `dark:hover:text-gray-200` |
| `hover:text-gray-800` | `dark:hover:text-gray-200` |

Additional rules:

- Semantic badges and alerts keep their color meaning: `bg-emerald-100 text-emerald-800` becomes `dark:bg-emerald-950 dark:text-emerald-200`; apply the same pattern for red, amber, blue, yellow, and indigo.
- Secondary buttons switch to dark surfaces, light text, and dark borders. Primary indigo buttons keep white text; use `dark:hover:bg-indigo-500` where useful.
- Inputs, selects, and textareas get `dark:bg-gray-900 dark:text-gray-100 dark:border-gray-700`; placeholders must remain readable.
- Page images get dark borders but no filters or inversion.
- Footer becomes `dark:bg-gray-950`; borders become `dark:border-gray-800`.

def _class_attributes(path):
    text = path.read_text()
    text = re.sub(r"<script\b.*?</script>", " ", text, flags=re.DOTALL | re.I)
    text = re.sub(r"<style\b.*?</style>", " ", text, flags=re.DOTALL | re.I)
    text = re.sub(r"<!--.*?-->", " ", text, flags=re.DOTALL)
    for match in re.finditer(r'class="([^"]*)"', text, flags=re.DOTALL):
        attrs = re.sub(r"{%.*?%}", " ", match.group(1), flags=re.DOTALL)
        attrs = re.sub(r"{{.*?}}", " ", attrs, flags=re.DOTALL)
        yield attrs


def missing_dark_variants(paths):
    missing = []
    for path in paths:
        for attrs in _class_attributes(path):
            tokens = set(attrs.split())
            for light, prefixes in DARK_PAIRS.items():
                if light not in tokens:
                    continue
                if not any(
                    token.startswith(prefix) for token in tokens for prefix in prefixes
                ):
                    missing.append(f"{path.relative_to(settings.BASE_DIR)}: {light}")
    return missing


def assert_dark_variants(paths):
    missing = missing_dark_variants(paths)
    assert not missing, "Missing dark variants:\n" + "\n".join(sorted(missing))

At the start of `<head>` in `templates/base.html`, before `{% tailwind_css %}`, add:

```html
<script>
(function () {
    var STORAGE_KEY = "civic-theme";
    var root = document.documentElement;
    var media = window.matchMedia("(prefers-color-scheme: dark)");

    function storedMode() {
        try {
            var value = localStorage.getItem(STORAGE_KEY);
            return value === "light" || value === "dark" ? value : "system";
        } catch (error) {
            return "system";
        }
    }

    function resolved(mode) {
        return mode === "system" ? (media.matches ? "dark" : "light") : mode;
    }

    function syncButton(button) {
        var next = {system: "Light", light: "Dark", dark: "System"};
        var names = {system: "System (follow device)", light: "Light", dark: "Dark"};
        var label = "Theme: " + names[current] + " — switch to " + next[current];
        button.setAttribute("aria-label", label);
        button.setAttribute("title", label);
    }

    function apply(mode) {
        var theme = resolved(mode);
        root.classList.toggle("dark", theme === "dark");
        root.dataset.themeMode = mode;
        root.style.colorScheme = theme;
        document.querySelectorAll("[data-theme-toggle]").forEach(syncButton);
        root.dispatchEvent(new CustomEvent("themechange", {
            detail: {mode: mode, theme: theme}
        }));
    }

    var current = storedMode();
    apply(current);

    window.civicTheme = {
        get mode() { return current; },
        set: function (mode) {
            if (mode !== "light" && mode !== "dark" && mode !== "system") return;
            current = mode;
            try {
                if (mode === "system") {
                    localStorage.removeItem(STORAGE_KEY);
                } else {
                    localStorage.setItem(STORAGE_KEY, mode);
                }
            } catch (error) {}
            apply(current);
        },
        cycle: function () {
            var next = current === "system" ? "light" : current === "light" ? "dark" : "system";
            this.set(next);
        },
        resolved: function () { return resolved(current); },
        syncButton: syncButton
    };

    media.addEventListener("change", function () {
        if (current === "system") apply(current);
    });

    window.addEventListener("storage", function (event) {
        if (event.key === STORAGE_KEY) {
            current = storedMode();
            apply(current);
        }
    });

    document.addEventListener("DOMContentLoaded", function () {
        document.querySelectorAll("[data-theme-toggle]").forEach(syncButton);
    });
})();
</script>
<style>
    .theme-icon { display: none; }
    [data-theme-mode="system"] .theme-icon-system,
    [data-theme-mode="light"] .theme-icon-light,
    [data-theme-mode="dark"] .theme-icon-dark { display: inline-flex; }
</style>
```
